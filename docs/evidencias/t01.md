# T01 — Evidencia y estado de la primera entrega

**Fecha:** 20-10-2026. **Estado:** base local operativa; la tanda permanece abierta por comprobaciones externas pendientes.

## Funciona en local

- Monorepo, lockfile, Node 24, tipos estrictos, formato, lint y workflow CI preparado.
- Vue: panel coach, lista/filtros y ficha de alumnos de ejemplo, rutinas, ejercicios, marca editable, temas, vista del alumno, ejemplo de series y acceso/recuperación.
- API Fastify: liveness/readiness, OpenAPI, errores seguros con identificador, rate limit, CSRF con cookie firmada, sesión opaca con hash, Argon2id, recuperación de un uso y revocación.
- PostgreSQL 16.11 propio del proyecto: migración con checksum/bloqueo, roles de migración/API/worker separados, RLS que falla cerrado y verifica pertenencia de usuario.
- Worker/cola SQL: reserva concurrente, leases, reintentos y estado fallido; payload sensible se limpia al terminar. Almacenamiento privado con claves opacas y defensa contra recorrido de directorios.
- Backup AES-256-GCM de DB/medios y restauración en base/directorio aislados, con conteos y hashes contrastados.
