### Casos nuevos de API/DB

1. Catálogo global de solo lectura, CRUD propio, filtros y versión desactualizada.
2. Reserva repetida, conflicto de idempotencia y subida exacta a stream.
3. Foto/equipo y prohibición de relaciones entre estudios, incluso SQL con rol de API.
4. Conversión real a MP4 y póster, entrega 206/416/HEAD y denegación sin sesión o de otra organización.
5. Compartir con alumno explícito, leer publicado y retirar permiso.
6. Falso formato, archivo corrupto, duración excesiva, bytes inválidos e incompletos.
7. Reserva de cuota concurrente y máximo de cuatro cargas por organización.
8. Resultado atrasado, reintento versionado, cancelación y pérdida de lease.
9. Caducidad y limpieza de huérfanos conservando referencias válidas.
10. API disponible durante dos conversiones de estudios distintos y una sola conversión por estudio.

El ensayo de cimientos también comprueba que un backup falla si falta un archivo referenciado, en lugar de aceptar una copia incompleta.

## Límite concreto de WebKit en Windows

El motor nativo pidió la URL privada sin cookie (401). Una descarga `fetch` autenticada sí devolvió 200; el mismo motor rechazó el Blob MP4 con error de medio 4. Una prueba aislada con el clip servido públicamente sí cargó metadatos; ese archivo temporal fue retirado. Por eso no se atribuye el problema a una ausencia general de códec.

La prueba de biblioteca en Windows WebKit verifica la descarga autenticada y la conservación de las instrucciones en este caso, con anotación `platform-limitation`. No acredita reproducción de vídeo en ese motor. Chromium PC/móvil carga el vídeo privado. La aplicación mantiene cookies y autorización; no publica el almacenamiento para pasar la emulación. [Playwright explica las diferencias de medios por plataforma y recomienda macOS para aproximarse a Safari](https://github.com/microsoft/playwright/blob/main/docs/src/browsers.md).

**Puerta pendiente:** grabar/subir un clip representativo y reproducirlo con permisos en Safari de iPhone real y Chrome de Android real. Registrar dispositivo/SO, entrada MOV/MP4, orientación, teclado, safe areas, cancelación de carga, red interrumpida y revocación. No se declara T03 aceptada en teléfonos ni apta para alumnos reales hasta cerrar esa puerta y los pendientes de T01/T07.
