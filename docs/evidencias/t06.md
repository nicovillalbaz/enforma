## Incidencias resueltas durante QA

1. Alias de fecha duplicados hacían ambiguo el orden en listados; se usan `day_date` explícitos. Nueve controles iniciales DB pasaron tras corregirlo.
2. El primer recorrido de navegador no compartía la sesión del coach entre cliente API y página; se corrigió el fixture y pasó.
3. El caso adicional de cuotas intentó modificar una versión de plan y fue rechazado por la regla de inmutabilidad; se corrigió para crear versiones de prueba nuevas. Las 13 integraciones T06 pasan sin desactivar reglas.
4. La revisión visual detectó etiquetas SVG demasiado pequeñas al escalar un lienzo fijo. El ancho ahora sigue al contenedor. WebKit señaló una notificación circular al actualizar tamaño dentro de ResizeObserver; la actualización se difiere al siguiente frame y evita cambios idénticos. No se silencia el error del navegador.
5. La revalidación al volver del fondo conserva el formulario y el archivo seleccionado; si falla la autorización retira la vista. La prueba incluye ese regreso antes de subir la foto. La anulación del fixture selecciona explícitamente el valor 71, independiente del orden de UUID del mismo día.

6. Reintentar la subida de una foto eliminada devolvía una lectura vacía del registro protegido; ahora devuelve `PROGRESS_PHOTO_REMOVED` 409, conserva la eliminación y limpia archivos temporales. Se comprueba antes y después de depurar bytes.

## Puertas abiertas

- iPhone/Safari y Android físicos: teclado decimal, calendario, selector/HEIC, orientación, safe areas, lector de pantalla, 200 % texto/zoom real, fondo/bloqueo y reapertura. La aceptación de vídeo T03 y arranque frío WebKit Windows T05 sigue abierta; no equivale a un resultado de Safari físico.
- T07: instalación PWA por marca, facturación SaaS, revisión de políticas/retención/exportación/borrado integral y reconciliación de revocaciones después de restaurar. Fotos retiradas se ocultan inmediatamente; bytes retenidos 30 días y copias antiguas siguen su propia retención. El límite de 100 registros históricos de fotos requiere revisar uso prolongado.
- SMTP/VPS/TLS, Docker/PostgreSQL 18 ejecutados, respaldo externo/alertas, entrevistas y piloto con usuarios reales pendientes. El ensayo local no acredita esas puertas.
