# Ilustraciones de ejercicios

Las ilustraciones SVG en esta carpeta proceden de [Workout Guide](https://github.com/bryllim/workout-guide), creado por Bryl Lim a partir de dibujos originales de [Everkinetic](https://github.com/everkinetic/data). Licencia de las ilustraciones: [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).

Modificaciones en Forma: las ilustraciones blancas originales se recolorearon a azul oscuro (`#14263d`), se igualó el encuadre de las tres posturas de cada ejercicio y se ajustó el grosor de los contornos para el tamaño móvil. La aplicación escoge dos posturas por ejercicio para su secuencia. Se conservan los tres fotogramas SVG modificados en esta carpeta para permitir revisar y cambiar esa elección. Los dibujos modificados conservan la licencia CC BY-SA 4.0. El código de Forma tiene su propia licencia y no toma código de Workout Guide.

Fuente de cada SVG: `https://bryllim.github.io/workout-guide/frames/<slug>/frame-<1|2|3>.svg`. Los créditos y procedencia de cada ejercicio también constan en el [manifiesto original](https://cdn.jsdelivr.net/npm/@bryllim/workout-guide@1.0.0/manifest.json).
